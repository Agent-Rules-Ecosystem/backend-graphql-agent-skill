# ⚡ Comandos de GraphQL Agent Skill (`backend-graphql-agent-skill`)

| Comando | Acción | Descripción |
|---|---|---|
| `$gql` | Bootstrap | Inicializa la skill y carga contexto del dominio. |
| `$gql:audit` | Auditoría | Auditar esquemas GraphQL, resolvers, dataloaders y queries. |
| `$gql:schema` | Generación | Generar o refactorizar esquema SDL y tipos. |
| `$learnskill backend-graphql-agent-skill [propuesta]` | Aprendizaje | Registrar propuesta de mejora específica para `backend-graphql-agent-skill` en `overview/learning.md` |
| `$revlearnskill` | Revisión | Clasificar e inspeccionar propuestas de aprendizaje acumuladas en `overview/learning.md` |
